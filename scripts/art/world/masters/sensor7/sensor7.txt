# Sensor 7 colour master (WP23a AD-d, Art Director). Cell 20x40 art px, pivot (0.5, 1): feet on row 39, centre x 10.0.
# Front elevation. Full 1 px ink ring on every cell. Codes: scripts/art/world/pal.py. Era rows by erarecolor.py.
# Build: python -I scripts/art/world/build_sheet.py sensor7   Gate: python -I scripts/art/world/check_sheet.py sensor7
# STACKED OVERLAYS: every cell is a full 20x40 cell with the same pivot; the renderer draws tripod, then ONE head
# (headL / headC / headR / headUp), then ONE readout glyph, all at the same position. Head and glyph cells hold only
# their own pixels (sheets.py `overlays`: exempt from the feet-on-the-bottom-row check).
# tripod: round pan socket (rows 13-14, covered by the head's bottom ink row 13), iron body box x6..13 rows 15..23 with
#   the stencilled 7 (#c9b28a, x8..10 rows 17..21) and the LED socket (ink, cell (12, 17)), side readout box x13..17
#   rows 16..22 (blank dark window x14..16 rows 17..21), A-frame legs (wood #ad6236 / #8c4a2a, iron clamps rows 31-32,
#   rear leg = 2 px ink) to three feet on row 39: x2..4, x9..10, x15..17 (shadow dots at -6.5, 0, +6.5 art px).
# heads: box x5..14 rows 4..13 (headUp rows 5..13 + lens barrel rows 1..4), one round lens: headC centred 6x6 (x7..12
#   rows 6..11), headL / headR = 3/4 heads (AD2c: the old flank lens + barrel read as aiming at the machine): the side
#   panel shows, the lens glass still faces the viewer, ring 5 wide flush with the turn-side box edge, glass 3x4, no
#   barrel past the box (it watches the camera, never the machine; bible 3.6), headUp = barrel and lens
#   pointing at the sky. Glint #d9822b: row I bakes it to a sepia glint, row II to the faded rust #8c4a2a (bible: "small
#   red glint in the lens" in era II), rows III+ own.
# glyphs: the readout box only (x13..17 rows 16..22), glyph 3x5 in #f0a848 (row I #c9b28a, row II #ad6236): glyphDash
#   = "-", glyphOne = "1". The stencilled 7 and these two glyphs are the only text in the living-world art.
# LED: not an art frame. The renderer draws a 2x2 world px square over the socket: top-left = origin +
#   2 * WORLD_ENV.sensor7.ledArt = (2, -23) art px (AD-d set it from (3, -30)), i.e. cell (12, 17).
# Head tracking: the default framings (e1, s9) put the camera centre > 200 world px right of x 1384 -> headR (3/4: out at the viewer).
# PLACEHOLDER CELL (copy of tripod until WP23b): fog (lens fog overlay, era III).
