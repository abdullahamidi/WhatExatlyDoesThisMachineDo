# WP15 — Music bed per era, audio mix, perf pass vs budget (profiling smoke)

= roadmap row **WP16** (project numbering: WP13 finale, WP14 prestige, **WP15 music/mix/perf**). Goal: a subtle, loopable, synthesized
music bed per era (crossfades on era change, ducks under the finale chord), one coherent mix with its own MUSIC slider, and a measured
perf pass with a profiling smoke that fails on budget breach. Folds three small debts. No balance, art or content changes.

Baseline: WP14 committed (prestige, `confirmNewCycle`, new-cycle reset path). Re-measure test count at WP14 HEAD before W1; never lower it.
Measured now (pre-WP14 HEAD cab6000): app chunk 302.9 KB (gzip 88.5), phaser 1.48 MB, css 21.6 KB, `public/assets` 1.6 MB;
s13 idle `machineStats` maxMs ≈ 35 (wave every ~5–9 s; suspects: steam/calliope burst spawns (SteamFx bursts everyS 5–9), per-frame
allocation → GC, MachineLinks graphics redraw). Audio verified by code review only so far.

## D Decisions
- D1 **Own MUSIC bus + slider.** `SettingsState += musicVolume` (int 0..100, default 70). Additive optional field → save stays v2, missing → 70.
  Bus order: master → limiter → destination; sfx, ambient, **music** under master. Roadmap §3 already lists a music volume.
- D2 **Pure scheduler, thin synth.** All note choice/timing/harmony/crossfade/duck maths in `src/audio/musicMath.ts` (no WebAudio). Synth only
  plays `MusicNoteEvent`s on slot A/B and ramps slot / duck gains. Deterministic seeded PRNG (mulberry32): same theme + bar → same notes.
- D3 **Theme = highest owned keystone**: none→`mech`, generator→`elec`, boiler→`therm`, resonatorSpire→`reson`, nullChamber→`exotic`;
  ending phase choice/postgame→`restored`; phase sequence→ current theme ducked to 0. Reset / new cycle → `mech` via normal crossfade.
- D4 **Scheduling** rides the existing 200 ms audio tick: `eventsInWindow(theme, clockStartS, fromS, toS)` with `MUSIC.lookaheadS` 0.5
  (> tick + jitter) and ≤ `MUSIC.maxEventsPerCall` 16. Tab hidden → context suspended; on resume the music clock re-anchors to the next bar
  (no catch-up burst). Muted, master 0 or music 0 → no events scheduled at all (CPU 0).
- D5 **Crossfade** equal-power over `MUSIC.crossfadeS` 6 s; the new theme starts on its own clock at now + 0.1 s in the other slot.
- D6 **Ducking**: finale `swell` beat → music to 0 over 3 s (silent through the sequence); `chord` beat → switch to `restored`, duck 0.25 for
  `AUDIO.resolveChord.ms` (4 s) then ramp to 1 over 4 s. Reload in choice/postgame → `restored` at 1, no chord. Milestone → duck 0.5 for 1.5 s.
- D7 **CPU cap**: ≤ 3 nodes per music note (osc, optional 2nd osc, env gain), shared per-slot lowpass, `MUSIC.maxVoices` 8 live notes
  (excess events dropped and counted), no ConvolverNode; one music "space" echo (Delay 0.38 s, feedback 0.3, lowpass 1800 = 3 nodes);
  master DynamicsCompressor (1 node). Target ≤ 60 live nodes total, live voices (one-shots + music) ≤ 48.
- D8 **Mix by data**: per-era ambient bed trims (older beds recede as eras arrive) in `AUDIO.bedTrim`; limiter catches peaks.
- D9 **Bundle budget** re-baselined: app chunk ≤ 340 KB raw / ≤ 100 KB gzip (roadmap 200 → relaxed 300 in WP11; era data lazy-load stays
  deferred). Phaser chunk ≤ 1.5 MB, css ≤ 30 KB, `public/assets` ≤ 8 MB.
- D10 Headless Chromium renders WebGL in software → frame-time p95 is **report-only** unless `PERF_GPU=1`; CPU probes (machine, UI,
  finale, tree, heap, display objects, boot) are **asserted** (`PERF_STRICT=1` → exit 1 on breach).

### C1 Music data (`src/data/music.ts`, new; numbers tunable)
```ts
export type MusicThemeId = 'mech' | 'elec' | 'therm' | 'reson' | 'exotic' | 'restored';
export type MusicVoice = 'pluck' | 'pulse' | 'swell' | 'bell' | 'reverse' | 'warm';
export interface MusicNoteEvent { startS: number; durS: number; hz: number; gain: number; voice: MusicVoice; bass: boolean }
export interface MusicTheme { id; rootHz; scale: readonly number[] /* semitones, or ratios when just:true */; just?: boolean;
  progression: readonly number[] /* scale-degree chord roots, 1 bar each */; bpm; beatsPerBar; bars; variations;
  voice: MusicVoice; attackS; releaseS; lowpassHz; detuneCents; density /* 0..1 per 8th slot */; peak; bassPeak }
export const MUSIC = { themes: Record<MusicThemeId, MusicTheme>, keystones: [['generator','elec'],['boiler','therm'],
  ['resonatorSpire','reson'],['nullChamber','exotic']], busGain: 0.6, lookaheadS: 0.5, maxEventsPerCall: 16, maxVoices: 8,
  crossfadeS: 6, startDelayS: 0.1, duck: { finaleOutS: 3, chordLevel: 0.25, chordRampS: 4, milestoneLevel: 0.5, milestoneS: 1.5 },
  space: { delayS: 0.38, feedback: 0.3, lowpassHz: 1800, wet: 0.25 }, seed: 41 } as const;
export interface AudioStats { unlocked: boolean; running: boolean; theme: MusicThemeId | null; slotGains: [number, number];
  duck: number; liveVoices: number; musicVoices: number; dropped: number; peakDb: number | null }
```
