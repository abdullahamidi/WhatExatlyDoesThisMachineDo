## D Decisions
- D1 **Debug hook gated, not removed.** Installed only when `import.meta.env.DEV` or URL query has `debug` (`?debug`, `?debug=1`; `debug=0`
  → off). Smokes test the real prod build with `?debug=1`. Pure helper `debugEnabled(search: string, dev: boolean): boolean` in
  `src/utils/debugFlag.ts`. No other behaviour change in prod.
- D2 **Version** `APP_VERSION = '1.0.0'` in `src/data/version.ts` (test asserts equality with `package.json` version, bumped to 1.0.0).
  Shown in system menu SYSTEM tab footer `v1.0.0 · SAVE v2`. Save schema stays v2 (no bump).
- D3 **Two e2e layers.** (a) pure deterministic `GameSession` full run in Vitest (CI, ≤ 6 s); (b) browser smoke on the preview build via
  debug fast-forward, strict exit code.
- D4 **Balance sign-off = measured tables + assertions**; tuning only in `src/data/` and only if a sign-off row fails (expected: none).
  Profile D (casual + nightly offline) added to the greedy harness via an optional pure `schedule` option.
- D5 **Save compatibility matrix** = hand-authored JSON fixtures in historical shapes + one table-driven test. Unknown future version
  refused with backup kept (existing path).
- D6 **ASSET_GUIDE kept honest by a test**: every manifest id must appear in `docs/ASSET_GUIDE.md` (test reads the file with `fs`).
- D7 **Art fixes** touch only `public/assets`, manifest dims, painters, CSS. Max 2 fix rounds; residual minor items → Known issues.
