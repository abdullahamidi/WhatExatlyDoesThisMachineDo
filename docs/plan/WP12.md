### C1 Types (`src/data/types.ts`)
```ts
export type NumberNotation = 'suffix' | 'scientific' | 'engineering';   // same union as utils/format.ts (format.ts re-exports or imports this type)
export type UiScale = 100 | 125 | 150;
export interface SettingsState {
  muted: boolean;                       // existing
  masterVolume: number; sfxVolume: number; ambientVolume: number;   // int 0..100, default 100
  notation: NumberNotation;             // default 'suffix'
  reducedMotion: boolean;               // default false (bootstrap sets true on a NEW save when prefers-reduced-motion)
  screenShake: boolean;                 // default true; ignored (off) while reducedMotion
  statusMarkers: boolean;               // colour-independent extra cues (glyph + border pattern); default false
  uiScale: UiScale;                     // default 100
}
export interface StatsState {
  activeSeconds: number; offlineSeconds: number; longestOfflineSeconds: number;   // offline = credited (capped) s; longest = max report.elapsedSeconds
  clicks: number; purchases: number;    // manual + keyboard cranks; successful purchases
  lifetime: ResourceMap;                // cumulative across cycles (never reset by WP14 new cycle)
  maxPerSecond: ResourceMap;            // max rates.perSecond seen
  cycles: number;                       // 1 (WP14 increments)
  bestCycleSeconds: number | null;      // null (WP14 fills)
  startedAt: number;                    // epoch ms
}
export interface AchievementsState { unlocked: Partial<Record<AchievementId, number>> }   // id -> epoch ms
SaveEnvelope += stats: StatsState; achievements: AchievementsState      // written always; optional on read (default/derive)
LoadResult   += stats: StatsState; achievements: AchievementsState      // always filled
```
`AchievementId` comes from `ACHIEVEMENT_IDS` in `src/data/achievements.ts` (types.ts may `import type` it, or define the const there — T1a/T1b agree contract-first: **const lives in achievements.ts, types.ts imports type**).

### C4 GameSession (additive; `src/simulation/{GameSession,events,index}.ts`)
```ts
GameSessionOptions += stats?: StatsState; achievements?: AchievementsState;  settings?: Partial<SettingsState>   // normalized; stats default deriveStats(state, now)
get stats(): Readonly<StatsState>; get achievements(): Readonly<AchievementsState>
updateSettings(patch: Partial<SettingsState>): void    // normalizeSettings({...current, ...patch}); shallow-equal -> no-op; else revision++, emit 'settings'
setMuted(m) === updateSettings({ muted: m })
SessionEvents += achievement: { ids: AchievementId[] }  // one event per evaluation that unlocked >= 1 (coalesced)
SessionEvents.settings: emitted when ANY field changes
```
Rules: click → clicks+1 · purchase ok → purchases+1 · live update path → activeSeconds += dt (clamped dt only) · applyOffline → offlineSeconds += cappedSeconds,
longestOfflineSeconds = max(·, elapsedSeconds) · every setState (not reset) → addLifetimeDelta · rates recomputed (and in constructor) → bumpMaxRates ·
evaluate achievements after the milestone check in click / purchase / update / applyOffline (not in constructor; no events there) · reset() → emptyStats(now), empty achievements, emits 'reset' as today.
Era I–V numbers, rates and existing event order unchanged (achievement event fires last).

### C5 Persistence + export/import (`src/persistence/*`)
- `schema.ts`: `readSettings` → `normalizeSettings` (lenient); `readStats(input, state, nowMs)` (missing/invalid → `deriveStats`; per-field lenient: non-finite/negative → derived value; maps per key);
  `readAchievements(input)` (unknown ids dropped, non-finite timestamps dropped, missing → empty). Cosmetic data never fails a save.
- `codec.ts`: `serialize(state, settings, nowMs, meta?: { stats; achievements })` (meta omitted → fields omitted, old tests keep working);
  `parseEnvelope(raw: string, nowMs, migrations?) : { ok: true; envelope; migrated } | { ok: false; error }` = JSON.parse → migrate → validateEnvelope; `deserialize` uses it (behaviour unchanged).
- `exchange.ts` (new): `encodeSave(json: string): string` (base64 of UTF-8, standard alphabet, padded; works in Node 22 + browser via btoa/TextEncoder);
  `decodeSave(text): { ok: true; json } | { ok: false; error }` (trims whitespace/newlines, accepts raw JSON starting `{`, rejects > 1 MB or invalid base64);
  `parseImport(text, nowMs) = decodeSave → parseEnvelope` (never 'recovered'; error strings shown to the player, ≤ 80 chars).
- `saveManager.ts`: `save(state, settings, nowMs, meta?)`; `backup(key): boolean` copies the current raw save to `key`. `SAVE_PREIMPORT_KEY = 'wedtmd.save.preimport'` in `data/balance.ts`.
- `saveController.ts`: saveNow writes `session.stats` + `session.achievements`; `exportString(): string`; `importString(text): { ok: true } | { ok: false; error }`
  (ok → backup current to SAVE_PREIMPORT_KEY, write imported state/stats/achievements + CURRENT session settings with savedAt = imported savedAt (offline credited on next boot exactly like a load),
  then `suspended = true`: saveNow returns false without writing (unload handlers cannot overwrite), autosave disposed). Caller reloads the page. Also saves on 'achievement'.
- `startup.ts`: passes `load.stats` / `load.achievements` into the session.

## D Decisions
D1 Settings in the save envelope (C2). D2 Stats/achievements owned by GameSession (single source, saved by saveController, deterministic, testable without DOM).
D3 Hard reset clears stats + achievements, keeps settings. D4 Import = validate → write → `location.reload()` (boot path does migration/offline/renderer rebuild; no in-place swap).
D5 Achievement toasts coalesce: 1 unlock → title `RECORD LOGGED`, body = name (secret → name too, it is now earned); ≥2 → `N RECORDS LOGGED`, body = first 2 names + "…". tone 'system'.
D6 Volumes: gain = AUDIO.masterGain × master/100 (muted still wins → 0); two new buses under master: **sfx** (every `play*` one-shot) and **ambient** (every `set*` loop and `schedule*` series), gain = v/100, ramped AUDIO.rampSeconds. Music volume → WP16.
D7 Number notation via module default (C6) — avoids threading notation through ~10 call sites incl. simulation requirement labels.
D8 Accessibility baseline (always on, not a setting): tech node `aria-label` "<name>, <status word>, <level>, <cost>", min 12 px text in all UI CSS, `:focus-visible` 2 px outline + offset on every control,
locked badge = locked sheet + `icons16` lock + text "LOCKED". `statusMarkers` setting adds glyphs (icons16 lock/check via CSS) + border patterns (locked dashed, available double) on tech nodes.
D9 prefers-reduced-motion is read once by bootstrap only when `load.status === 'new'`.
D10 UI scale: `#ui-root` CSS `zoom` = uiScale/100 (set by bootstrap settings applier); canvas untouched.
