### C2 Auto-click effect (`src/simulation/production/{rates,tick}.ts`, `progression/status.ts`)
```ts
// computeRates: autoClicks = Σ perSecond*level over 'autoClick' effects of owned techs (level <= 0 ignored)
// 1) perSecond chain exactly as today (convert sees the chain values only)   2) perClick exactly as today (echo uses the step-1 perSecond)
// 3) FOLD: perSecond[r] += autoClicks * perClick[r] for every r            // after perClick; non-circular; chain and perClick unchanged by it
describeEffect({ type: 'autoClick', perSecond }, n) === `+${fmt(perSecond * n)} auto-cranks/s`
```
Consequences (all automatic, no other code change): advance() / computeOffline() / HUD "/s" / animator automation driver (perSecond.me) / greedy harness
include servo output; offline counts it (roadmap). Auto-clicks emit NO `click` event, do NOT bump `totalClicks`, spawn no floating text.

## D Decisions (planner)
1. **Auto-click fold (C2)** is the only economy change: one formula line, no new state, offline/greedy/HUD/animator follow for free. Echo and conversion use
   the pre-fold rates, so there is no feedback loop and the values stay deterministic.
2. **Servo visuals:** no per-auto-click impulse on θM (10 clicks/s × 90° would exceed `masterSpeed.max`); the servo arm and crank turn with θM, whose drift
   already rises because perSecond.me includes the servo. Fork ping and floating text stay manual-click only.
3. **R1 uses the crank angle state:** `servoArm` joins `CRANK_PARTS` (same crank offset/gearing as handCrank) and the link renderer asks the animator for part
   angles (`angleOf`), so the rod stays exactly vertical (parallel crank, length 32) at every angle.
4. **Reduced motion clamps** (ART_ERA4 §6) are deferred to the settings WP (no settings exist yet).
5. **Balance file runtime:** profile A at 1 s buys dominates (5.4 s alone at 12600 s). Fix in the harness: `getAllTechViews` once per buy tick, recomputed only
   after a successful purchase (identical results). Determinism check becomes a 3600 s prefix rerun of A compared with A's purchases/firstAt up to 3600 s.
