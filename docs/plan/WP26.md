## Contracts
- **C1** `src/game/context.ts`:
  - Type: `export interface WorldWeather { live: boolean; wind: number; virgaAlpha: number; virgaSpeed: number }`.
  - Field: `GameFeedback.worldWeather: WorldWeather`, a plain mutable readout, not a Signal. Default `{ live:false, wind:0, virgaAlpha:0, virgaSpeed:0 }`.
  - Only the director writes it; only gameAudio reads it.
  - `wind` = raw `out.ambient.wind` (0..1.5), never the reduced-motion-zeroed `ambient()` value.
  - `virgaAlpha` = `tween.virga.alpha × ambient.virgaAlpha`.
  - `virgaSpeed` = `tween.virga.speed × ambient.virgaSpeed`.
- **C2** `src/data/audio.ts`:
  - `wind` gains `refWind` and `floor`.
  - New `rain` block: gain 0.025-0.032 (−30 dB ±2), filter, `alphaRef` 0.7, `speedRef` 1, pitch range.
  - `BedId` gains `'rain'`, with `bedTrim.rain` = `[1,1,1,0,0]`.
  - The era III re-trim goes on the boiler, not the wind (the bible says the front builds), so `ambientPeakSum(3)` stays ≤ 0.45. Era III is at 0.444 today.
- **C3** `src/audio/audioMath.ts` (pure): `weatherMix(input | null, era, muted)` → `{ windGain, windLfo, rainGain, rainHz, live }`.
  - Wind when live: `gain × (floor + (1−floor) × clamp01(wind/refWind))`, no LFO. Not live: v0.10.0 behaviour.
  - Rain: `gain × clamp01(α/alphaRef) × clamp01(speed/speedRef)`.
  - `AmbientMix` gains these fields, so the smokes can read them through `audioStats().ambient`.
- **C4** synth:
  - A wind level setter (gain plus LFO on/off).
  - `setRain(gain, hz)`: nodes are created on the first gain > 0 and stopped in `close()`.
  - `LevelSnapshot.wind` (boolean) stays the gate for mute, choice/postgame and windStop.

5. **Headless frame clamping** (about 8x under WP24 D9) makes long fades look partial in PNGs taken without settle. stages and tiers PNGs are look-only, so a partial sky there is not a defect.

7. **The girl's new x could fail the wing rule** in s8/s9 and put her off stage. The unit pins catch it.
8. **The new required `GameFeedback` field** needs the gameAudio.test fixture updated in W1, or typecheck breaks.
9. **WP26 must branch from the v0.10.0 close commit**, which includes F4 and STEAM_RELEASE §15.
10. **Slot moves change tree screenshots.** Store shot 05 (tab III) changes only if AD1 moves a tab III slot; it should not, since F4 is already in.
