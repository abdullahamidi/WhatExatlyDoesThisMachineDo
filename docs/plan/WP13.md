## D Decisions (planner)
1. **Trigger = state, not event replay.** The finale starts on the `ending` session event; on boot the director reads `state.ending` (normalised): `choice` →
   S5 end state (overlay with all lines + buttons, restored world), `postgame` → restored world, no overlay. Reload mid-sequence therefore resumes at the choice
   (roadmap acceptance). WP11 saves owning primaryFunction load as `choice` (they get the reveal text + choice without the cinematic).
2. **S5 start derived from text** (`choiceStartS` = 62.6 s, end 64.5 s) instead of the storyboard's "≈71": 30 cps + 2.0 s pauses are kept exactly; tune `holdS`.
3. **Clock:** director `t` advances by Phaser delta clamped to 250 ms per frame (a hidden tab pauses the film); `seek(t)` fires crossed beats (`beatsBetween`),
   `skip()` jumps to `finaleEndS()` and fires only the state beats `plate` + `chord` (no swell/white/calliope stings) and `finishEndingSequence()`.
4. **Input:** during `sequence` + `choice` the overlay pushes `'finale'` on the modal stack (crank already disabled by WorldScene's `modals.isOpen()` gate);
   Esc → skip in `sequence`; at `choice` Esc does nothing (close fn re-pushes). Opening the finale closes the tech tree / system menu (`closeDialogs`).
   HUD + toasts fade (`#ui-root.finale-active`, 1.0 s CSS opacity, pointer-events none); restored on KEEP IT RUNNING.
5. **New cycle in WP13 = disabled stub** (`createNewCycleStub`): button shown, `aria-disabled`, reason text visible under it. Same button in the system menu
   while phase is `postgame` (no lockout rule satisfied once WP14 plugs `begin`). No reset-based placeholder (would delete progress without Echoes).
6. **xf label revealed** (roadmap: `???` until finale): HUD rows, welcome-back text and tree tab header use `REVEALED.xf.short` once `isRevealed`; tech
   descriptions keep `???` (lore text). Plaque → `PRIMARY FUNCTION: RESTORE`.
7. **Ground + regrowth are not PARALLAX_LAYERS rows** (ART §7 listed them): they need the wipe mask, so `RestoredGround` owns them (`RESTORED_GROUND` data).
   Geometry = Terrain's (same `layerPhase(1, 256, PIXEL_SCALE)` shift) so tile seams match the ruined ground. Masks exist only during the 16+8 s wipe.
8. **Reduced motion** = `prefers-reduced-motion` (no settings field yet; settings WP swaps the source). Variant per ART §7: camera cuts with 0.4 s fade through
   the current sky colour, white ≤ .5 (1.0 s), ground/regrowth 3 s crossfade, static beam frame, no birds/seeds, eclipse without diamond, lines appear whole.
9. **Audio (CR-K, minimal):** `swell` reuse at S1, `chord` = new resolving major chord at S5, `windStop` (wind off from S3 and in choice/postgame), `flock` =
   2–3 synth chirps. Mix polish = roadmap WP16.
10. **Postgame machine:** boost 0 (idles on real rates), plate frame 5, white beam α .85, eclipse/violet/glow hidden (draw-call saving), dust → seeds ⅓ rate.
