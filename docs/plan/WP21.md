## D — Decisions

- **D1 Edition source = Vite mode.** `editionFor(import.meta.env.MODE)` is called only in `src/main.ts`. Demo end UI is a lazy chunk loaded behind
  the literal `import.meta.env.MODE === 'demo'` so Rollup drops it from the full build (full `dist/` carries no demo-end code/CSS).
  Web demo builds into `dist-demo/` (`npm run build:demo`), never into `dist/` (port 4175 keeps serving the production dist).
  Desktop packaging builds into `build/vite-<edition>/` (no longer clobbers `dist/`).
- **D2 One cap rule: `maxEra` = 2.** Era > maxEra techs: purchase refused with reason `'demo'`, status `'locked'`, `demoLocked: true`
  in TechView, milestones skipped, never affordable, next-goal sequence filtered (so it ends at substationBlueprint). `capTech`
  (`substationBlueprint`, era-2 auto milestone) is only the trigger of the demo end. Full edition: `maxEra null` = byte-for-byte old behaviour.
- **D3 Saves never mix.** Same keys inside each edition's own storage: Electron demo userData `WhatExactlyDoesThisMachineDo Demo`
  (full: `WhatExactlyDoesThisMachineDo`), web demo is a separate origin. Demo boot clamps the loaded save: era>2 tech levels → 0,
  res/lifetime of pr/rs/xf → 0, ending → `{ phase: 'none', engagedAt: null }`, prestige → default (cycle 1, 0 echoes, no perks).
  When the clamp changed anything, the untouched stored string is first copied to `wedtmd.save.fullgame` (then the boot save writes
  the clamped state; later boots have nothing to clamp, so the backup keeps the original). Import (DATA tab) goes the same way on the
  reload. Demo → full carry-over is not automatic (DATA export/import works; documented).
- **D4 Tree.** Era III–V tabs read `FULL GAME`, disabled (no peek into era III+ nodes). Derived in the view from `demoLocked` views;
  `techTree.ts` unchanged.
- **D5 Demo end flow.** capTech `milestone` event → +4000 ms (re-checked every 1000 ms while title / credits / cycle confirm block)
  → teaser: close tree + menu, root class `demo-teaser-on` hides every other `#ui-root` child, caption (kicker + redacted name), SKIP chip;
  `ShowcaseScene.play` (World sleeps; the controller calls `session.update()` every 1000 ms so no offline report on wake) →
  `onDone` + 1500 ms hold → END card over the teaser end frame. Esc / click / SKIP during teaser → `skipToEnd()` (seek 9.5 s) → card.
  KEEP TINKERING (or Esc on the card) → card closed, `ShowcaseScene.stop` wakes the World. REPLAY TEASER on the card → teaser → card.
  Boot with cap owned → card over the live World (after the title closes with CONTINUE; at once when no title). Boot where the offline
  catch-up crossed the cap (cap 0 in the stored save, 1 after boot) → teaser instead. SYSTEM tab row `DEMO ENDING` re-opens the card.
- **D6 Wishlist target = FULL game app** (placeholder `0000000`): desktop `steam://store/0000000` via `host.openExternal` (Steam client),
  web `https://store.steampowered.com/app/0000000/` via `window.open(url, '_blank', 'noopener,noreferrer')`. QUIT only with a host.
  `feedbackUrl` = null in this package (button hidden). Any non-null URL must start with a `desktop/main.cjs` EXTERNAL_ALLOW prefix (test).
- **D7 Redacted name is data-driven:** caption = the `PLAQUE_LINES` row whose milestone is capTech → `PRIMARY FUNCTION: RES?OR?`

- **D8 Demo hides:** RECORDS filtered to 18 of 33 (rule C7), MEMORY tab, settings CONFIRM NEW CYCLE row, STATS CYCLE / BEST CYCLE rows and
