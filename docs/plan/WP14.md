## D Decisions (planner)
1. **Echo power counts all earned Echoes** (roadmap: unspent only). Measured table: the unspent rule misses ≤ 65 % and makes every perk a trap. Perks
   now cost Echoes only as a spending budget; spending never lowers the bonus → no trap, choice = order. Panel text `ECHOES 3 (+90% ALL/S) · UNSPENT 1`.
2. **+30 % all per-second per Echo, counted up to 30 Echoes** (cap = +900 %; E40 all perks still 15 % of c1, no stall/overflow). Clicks unaffected.
3. **Echo formula = base 3 + one per threshold** `[2e9, 8e9, 3.2e10]` of this cycle's `state.lifetime.xf` (roadmap `3 + min(3, floor(log10(xf/1M)))`
   gives 5 at the PF purchase (5.36e8) and 6 within 35 min — the bonus range would be meaningless). Immediate new cycle = 3; KEEP IT RUNNING
   ≈ 50 min → 4, ≈ 2.7 h → 5, overnight → 6. Only possible after the current cycle's reveal (D7), so era progress is always complete.
4. **Memory effects = derived tech table** (`cycleTechs`). No new TechId, no GameState field, pure layer already threads `techs` everywhere; the
   greedy harness takes `initial` + `techs` unchanged. Echo multiplier / Long Silence / Servo Recall ride on Hand Crank (always owned), so its tree
   card lists them (intended: discoverable). `META_MULT` stays 1 (unused path kept).
5. **Servo Recall = `autoClick +1/s`** (roadmap: crankServo lv 1 at start). An owned repeatable with unmet prereqs shows `available` but purchase
   returns `locked`, and the greedy picker would stall ME buys on it. crankServo stays fully purchasable (max total 11/s). No servo arm until bought.
6. **Perks act immediately** when bought (Muscle Memory raises wornMotor/gearRatio now), persist through every new cycle, single click, one level each.
7. **New cycle only from a revealed run** (`ending` choice/postgame); every cycle replays to primaryFunction. Hook blocked otherwise / while busy.
8. **Hard reset** (SYSTEM → RESET PROGRESS) wipes prestige + stats + achievements, keeps settings (existing "ERASE ALL" wording holds).
9. **Save:** envelope key `prestige` (codec's `SaveMeta` name already means stats+achievements), additive, lenient read, v2. Old saves → cycle 1.
10. **Confirm dialog = pre-cycle screen** (setting `confirmNewCycle`, default ON, toggle in SETTINGS): title `BEGIN CYCLE 0043?`, `+3 ECHOES → ECHOES 3
   (+90% ALL/S)`, next-threshold hint (`+1 ECHO AT 2B RF`, xf short via WP13 `REVEALED` since the run is revealed), KEPT / RESET lists, buttons
   `BEGIN CYCLE 0043` (icons16 frame 1) + `CANCEL`; Esc = cancel. OFF → transition starts at once. Works over the finale overlay and the menu.
11. **Transition** per ART §7: white α 0→1 0.8 s, swap at the peak (`beginNewCycle` → existing `reset` rebuild: machine, sky, eclipse, beam, camera,
   tree, director neutral frame), α 1→0 1.5 s; input locked by a `'cycle'` modal; reduced motion (`settings.reducedMotion`) 0.5 s / 0.5 s.
   After it: HUD `CYCLE 0043` line, toast `CYCLE 0043` / `+3 ECHOES (+90% ALL/S)`, stamp SFX, `#ui-root.finale-active` removed, modal stack empty.
12. New cycle replays the unrevealed lore (plaque, `???` label, system logs) — "Cycle has no beginning". No change to WP13 reveal rules.
13. Stats: `cycles` = prestige.cycle; `bestCycleSeconds` = min wall-clock (engagedAt − createdAt), offline time included.
