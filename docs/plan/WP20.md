## D Decisions
- D1 **Fly-in after close.** While the TECH INDEX is open, newly visible parts get their assembly tween created **paused** (sprite alpha 0, kept in `assembling`, so links/shadows/pylon cables already treat it as assembling). On tree close they play in order with `delay = min(i, ASSEMBLY_QUEUE.maxStaggerSteps) × ASSEMBLY_QUEUE.staggerMs` (120 ms, cap 8). Auto-frame on purchase stays as is. No auto-close of the tree.
- D2 **Camera nudge** on release toward the centroid of released parts: none when the target is inside the inner box (`innerFraction` 0.5 of the view), else move 35 % of the offset, capped 160 world px, tweened with the existing `animateTo` (450 ms). Skipped under reduced motion (`cameraTween` false), during an active drag, while the finale override is set, or while a refocus tween runs.
- D3 **Toasts above the backdrop.** While the tree is open the stack keeps z 200 (overlay z 100) and moves top-left (over the static TECH INDEX title, never over CLOSE [ESC] or PURCHASE). `maxVisible` 2 unchanged.
- D4 **Tree feedback** = `INSTALLED — <INSTALL_LINES[id]>` on level 1, `LEVEL n` above. `#tech-feedback` min-height 2.8em (no layout shift).
- D5 **Keyboard.** Open focuses the selected node (fallback CLOSE). A keyboard activation (`click` with `detail === 0`, i.e. Space/Enter) of the **already selected** node = PURCHASE; a mouse click only selects. Space never closes the tree unless CLOSE itself has focus.
- D6 **Fit.** Layout node 144 / gap 14 / row gap 28 / padding 18 / height 68 → max era width 36 + 7·144 + 6·14 = **1128 ≤ 1140**. When the graph viewport is narrower (UI 150 %: 782 CSS px), `.tech-graph-inner` gets CSS `zoom = clamp(viewport/content, 0.6, 1)` (≈0.69 → on-screen scale ≈1.04). Reveal of the selected node is manual (`revealScroll`), not `scrollIntoView` (it scrolls overflow-hidden ancestors).
- D7 **Default selection**: priority pick = `primaryFunction` when available, else an available not-owned keystone (`ERA_KEYSTONES`); then first affordable unlock; first affordable; first available non-starting; `handCrank`; first view. On open the priority pick overrides a remembered selection.
- D8 **Onboarding.** Crank prompt `> TURN THE CRANK [CLICK / SPACE]` = Phaser text in world above the frame (named `crank-prompt`), blinking `_` cursor (static under reduced motion), shown while `totalClicks === 0` (also after a hard reset). Ring radius 24 art px, α 0.9, ink outline. TECH INDEX hint = DOM callout over the HUD buttons + pulse on `#hud-tech` while: clicks > 0, no non-starting tech owned, ≥ 1 affordable, phase `none`, tree closed, cycle 1. Affordable badge on `#hud-tech` whenever count > 0 (all eras). No save field.
- D9 **Next goal** line in the HUD panel (under the plaque/cycle line), shown after the first purchase while phase is `none`. Goal = first not-owned id of `NEXT_GOAL.sequence`. ETA uses per-second rate only (clicks excluded).
- D10 **Era cards** on keystone unlock (generator, boiler, resonatorSpire, nullChamber; never primaryFunction): DOM `#era-card`, top 18 %, centred, z 80 (above HUD, below tree 100), visible 2400 ms + fades, click to skip, deferred while the tree is open (latest wins), dropped on `ending` phase ≠ `none` and on `reset`. Reduced motion: no animation, same timing.
- D11 **Toast coalescing**: purchase toasts of the same tech within 1500 ms of the previous one merge: `GEAR RATIO — LV 1 → 4` (single step stays `GEAR RATIO — LV 4`).
- D12 **Menu**: `#system-panel` height `min(86%, 620px)` on every tab, themed thin scrollbar; square themed radios; MEMORY tab and CONFIRM NEW CYCLE row visible only when `prestigeUiVisible(phase, cycle)` = cycle > 1 or phase `choice`/`postgame`.

`nextGoal` rules (phase ≠ `none` or all owned → null; title `NEXT: ${def.name.toUpperCase()}`):
| case | detail | ready | progress |
|---|---|---|---|
| a tech requirement unmet (first in `requires` order) | `NEEDS ${requirementLabel(req).toUpperCase()}` e.g. `NEEDS PISTON ARRAY`, `NEEDS CONDENSER LV 5` | false | 0 |
| milestone, tech reqs met | `${formatNumber(lifetime)} / ${formatNumber(amount)} LIFETIME ${short}` + ` · ~${formatDuration(ceil(remaining/rate))}` when rate > 0 | false | min(1, lifetime/amount) |

| unlock not affordable | `${formatNumber(res)} / ${formatCost(cost)} ${short}` + ETA as above (rate = perSecond[costRes]) | false | min(1, res/cost) |
