## D — Decisions
- **D1 Display levels are rendering-only.** A `DisplaySource` wraps the session as a `MachineSource`. Its `state.techLevels` = `mergeDisplayLevels(real, override)`. WorldScene passes it to MachineView, Eclipse, ApertureBeam and SteamFx only. The following keep reading real levels: simulation, saves, HUD, CameraController (auto-frame), ParallaxBackground, PylonLine, DustField, FinaleDirector phase. The economy is never touched.
- **D2 visualMax is derived, never hand-listed.** `visualMaxLevels()` = per tech, the max over every MACHINE_COMPONENTS gate:
  - `techId`/`minLevel`
  - each `alsoVisibleWith` entry
  - `latch` animation gate
  - `stage` animation gates

  Result (45 techs, snapshot-tested): copperWinding 20, firebox 20, harmonicCoil 25, containmentRing 25, resonantSiphon 20, graviticAnchor 10, every other gated tech 1 (incl. skyAperture via latch, the 4 blueprint/convergence milestones via the namePlate stage, bellowsDrive/gridExciter/mainsBackfeed/steamLance). Absent: motorTuning, improvedPistons, horizonField, finalAlignment, primaryFunction.

  `sceneMaxForEra()` adds the world gates for the teaser only: PARALLAX_LAYERS visibleWhen/alphaStages, ECLIPSE.stages, PYLON_FEEDS gate, DUST_RISING (adds horizonField 20).
- **D3 Completion beat.** Steps at S1 t = 3 / 4.5 / 6 s raise every tech with `TECHNOLOGIES[id].era ≤ 3 / 4 / 5` to visualMax.
  - Fly-in uses the existing assembly (drop, dust, shake, `partLanded`). It runs only in phase `sequence` and only when not reduced.
  - Instant (`refresh(false)`): reduced motion, skip, boot into choice/postgame, seek backwards.
  - choice and postgame = era 5. none = no override.
  - Reset / new cycle clears the override: DisplaySource subscribes to base `reset` first, so it runs before MachineView.
- **D4 Survey camera** in the idle S3 window: three keys baseL → baseR → full. They end exactly at `FINALE_SHOTS.s4` (49.3). Under reduced motion they are skipped (no cut fades). Beats, shots, tracks and audio timings are unchanged.
- **D5 Canonical portrait pose** = `FINALE_VIEWS.full` → camera (1920, 1080, 0.5) = whole machine + sky. `CameraController.target()` returns it in choice/postgame. So live KEEP, reload into postgame and REFOCUS all give the same pose. The finale name plate (DOM S4) and the machine namePlate sprite frame 5 stay as they are.
- **D6 Restored accent v1 = "lamps lit".** In the restored state with boost 0, lamp/glow frame parts hold their bright frame. `RESTORED_ACCENT.holdFrames` = FINALE_BOOST.holdFrames (anchorGlow1-3 L/R → 2, lensLight → 3) + crystal → `RESONANCE_MILESTONE_FX.holdFrame` (2). No tint: a multiplicative tint cannot turn violet white. A violet → warm-white core needs an art variant (Director note to A17 / Art Director).
- **D7 Photo mode = modal `photo` on the shared ModalStack.**
  - Esc closes it via `bindEscapeToStack`. Hotkeys (Space) and the menu are suppressed because `modalOpen` is true.
  - WorldScene keeps Phaser input enabled while `photo` is the top modal, so the existing drag + wheel pan/zoom work (already clamped to the world).
  - The HandCrank zone is disabled. `#ui-root.photo-mode` hides every #ui-root child except the exit chip.
  - Enter tweens to the portrait pose. Exit restores the portrait pose in postgame, or the entry pose when debug-forced in phase none.
  - Auto-exit when any other modal becomes top (e.g. `T` opens the tree) or the phase becomes sequence/choice.
  - Allowed for the player only in postgame with no modal open. Debug/smoke may force it in phase `none`. Never in sequence/choice.
- **D8 Keyboard.** VIEW MACHINE is a HUD `<button>` (Tab/Enter), visible only in postgame. In photo mode:
  - Arrows pan 96 screen px.
  - `+`/`=` zoom in one 0.25 grid step; `-`/`_` zoom out.
  - Esc exits.
  - Exit chip `EXIT VIEW [ESC]` gets focus on enter. It fades out after 2500 ms and fades back in for 2500 ms on pointer move or focus. It stays focusable.
- **D9 ShowcaseScene.**
  - Separate Phaser scene in the same game, key `Showcase`, registered lazily with `game.scene.add` on first play (never in bootstrap).
  - Own camera, set directly from the pure `teaserFrame()`. Own scripted `StandInSource`; its rates come from `computeRates` of the scripted levels.
  - World is slept while it plays (the simulation pauses and catches up on wake) and woken on stop.
  - Never restored, no DOM. WP21 adds the end card and name redaction.
- **D10 Showcase shots.** Playwright viewport 1280×720, `deviceScaleFactor: 3` → 3840×2160 PNG. No render-resolution change (that is a later display package).
- **D11 Scope guard.** No change to simulation, balance, save schema, audio or art assets. Any need to touch a forbidden file goes into a Director note.
