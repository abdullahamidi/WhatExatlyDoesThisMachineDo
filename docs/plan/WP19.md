**Verified while planning** (headless Chromium 141 and Vite 6.4.4 builds in scratch; numbers are load-bearing):
- **CSS `zoom` on `#ui-root` also scales the root's own box.** It multiplies the element's own left/top/width/height: root left 100 / width 640 at zoom 2 gives rect x 200, w 1280. So **root box = canvas rect ÷ zoom**.
- **`contain: layout` on `#ui-root` re-anchors fixed children.** `position: fixed` descendants (hud.css) then resolve against the root: a fixed child at 16/16 lands at root + 32 px at zoom 2. **hud.css needs no edit.**
- **Percent heights fit the canvas; vh does not.** `max-height: 94%` inside the canvas-anchored root gives 676.8 px for a 720 px canvas. `calc(94vh / zoom)` at a 1280×800 viewport gives 752 px, which is larger than the 720 px canvas and therefore clips.
- **Vite keeps relative public URLs as they are.** `./boot.js`, `./assets/ui/logo.png` and `./assets/ui/logo-mark.png` stay relative in `index.html`, and `public/boot.js` is copied to `dist/boot.js`. Vite prints one harmless warning: "`<script src="./boot.js">` can't be bundled without type=module".
- **Phaser's frame limiter judders at limit 60.** Phaser 3.90 `TimeStep.stepLimitFPS` sets `this.delta = 0` after each step. Simulated with ±0.15 ms jitter:

  | 60 | 30 | 60 |
  | 75 | 37.5 | 75 |
  | 90 | 45 | 45 |
  | 100 | 50 | 50 |

## D: Decisions (these win over older plan docs for this package)

- **D1 Electron toolchain.**
  - devDependencies pinned exact: `electron` 44.7.0, `@electron/packager` 20.3.0, `@electron/fuses` 2.1.3.
  - Main and preload are CommonJS in `desktop/`.
  - The app is staged into `build/desktop-app`, packaged into `out/steam/<edition>/win-x64/`.
  - `<edition>` = `full` for Vite mode `production` and `demo` for mode `demo`. Demo gating itself is WP21.
- **D2 Origin and CSP.**
  - Origin is `app://wedtmd`, a privileged scheme. Files are read from `dist` with a path guard and a MIME map, and every response carries the CSP header.
  - CSP `script-src 'self'` forbids inline scripts. The boot performance mark therefore moves to an **external classic script `public/boot.js`**, loaded before the module. It runs before any module code, which is the same effect the brief wanted from an inline script, and it is CSP-safe.
  - `main.ts` drops its `performance.mark` line, because ES import hoisting made it run after Phaser had loaded.
- **D3 Host saves.**
  - The renderer keeps a sync-loaded cache. Writes coalesce in a **500 ms window that later writes do not restart**, so latency is at most 500 ms.
  - `bridge.flush(pending)` sends every pending write in ONE `sendSync`, so correctness does not depend on IPC ordering. This deviates from a no-argument `flush()`.
  - Main writes `userData/saves/<key>.json` as `.tmp` → fsync → rename, and keeps the previous file as `<key>.json.bak`. Keys must match `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$` and must not contain `..`.
  - userData location:
    - packaged: `%APPDATA%/WhatExactlyDoesThisMachineDo`
    - unpackaged: `…-dev`
    - env `WEDTMD_USER_DATA` (absolute path) overrides both, for smokes.
  - One-time import from localStorage happens when the host has no `wedtmd.save`.
- **D4 Memory-fallback warning is a persistent banner `#storage-warning`, not a toast.** The toast stack has `maxVisible` 2, evicts the oldest and clears on reset, so a toast would disappear.
- **D5 Crash guard.**
  - Only the first error opens the overlay.
  - The saver is registered by bootstrap.
  - The overlay is appended to `<body>`, so it works even when `#ui-root` is missing.
  - `ResizeObserver loop…` messages are ignored.
  - The guard is installed in `main.ts` before `bootstrap()`, which runs inside try/catch.
- **D6 Debug gate.** `debugEnabled(search, dev)`: an explicit URL flag wins over `dev`. The hook is never installed when the host is packaged. Every browser smoke passes `?debug=1`, because the preview build is a production build.
- **D7 Title screen at boot.**
  - It is shown unless one of these holds:
    - the ending phase is `sequence` or `choice` (the finale is its own screen);
    - the URL has `title=0`;
    - the URL `debug` flag is on and `title` is absent.
  - The `debug` rule keeps every existing smoke working unchanged with `?debug=1`, including `stages.mjs`, which this package may not edit.
  - Esc means CONTINUE (dismiss).
  - NEW GAME with a save needs a two-step confirm: the existing `reduceReset`, 5 s.
  - Boot notices (recovered / welcome back / boot achievements) are held until the title closes, and dropped on NEW GAME.
  - Audio unlock needs no code: `gameAudio` already listens for gestures in the window capture phase.
- **D8 Credits** are one shared modal, opened from the title and from the SYSTEM tab. The content credits Phaser (MIT), Electron/Chromium, PixelLab-assisted art, synthesized audio and the author `abdullahamidi`. `THIRD_PARTY_NOTICES.txt` sits in the repo root and next to the exe.
- **D9 UI anchoring.**
  - `#ui-root` gets `contain: layout`.
  - Root box = canvas rect ÷ zoom.
  - `zoom = uiZoom(canvasH, uiScale) = max(1, canvasH/720) × uiScale/100`, rounded to 4 decimals and capped at 6.
  - The **floor of 1** keeps text at 12 px or more in windows shorter than 720 px. This deviates from the brief's formula.
  - Panels use **percent of the root** (`max-height: 94%`, `width: min(1180px, 96%)`) instead of `calc(94vh / zoom)`, because vh spills past the canvas at 1280×800.
  - The remaining viewport-unit rules use `calc(Nvh / var(--ui-zoom, 1))`.
  - `position: fixed` becomes `absolute` in the CSS files this package owns.
- **D10 Frame cap.** `FRAME_RATE = { target: 60, limit: 78 }` (see the table above). A limit of 60 judders on 60 Hz panels. 78 leaves 60/75 Hz untouched, runs 120/240 Hz at 60 and 144 Hz at 72; 90 Hz panels (Deck OLED) run at an even 45. A pure accumulator test guards these numbers.
- **D11 Fullscreen is not a SettingsState field** (no types.ts change). The host persists it in `window.json`; on the web it lasts for the session only. Alt+Enter is handled by main in the host and by the `fullscreen.ts` listener on the web. F11 on the web is the browser's own fullscreen.
- **D12 Version.**
  - `APP_VERSION = '0.9.0'` is a literal in `src/data/version.ts`. `packageVersion.test.ts` ties it to the root and desktop `package.json`.
  - Version line: `v0.9.0 · SAVE v2`.
  - Edition seam: `bootstrap({ editionLabel })` and the 3rd argument of `versionLine()`. The default is null; WP21 passes `'DEMO'`.
- **D13 The splash lifecycle is owned by `BootScene` + `splash.ts`.** Progress comes from the Phaser loader. The first frame is detected with a `PerformanceObserver` on the existing `wedtmd:first-frame` mark, so WorldScene is not edited.
- **D14 Window.**
  - 1280×720, minimum 960×540, background `#0d0b09`, shown on `ready-to-show`.
  - Bounds and fullscreen persist in `userData/window.json`.
  - On first launch (no window.json), fullscreen is on when `process.env.SteamDeck === '1'`.
- **D15 Dev vs packaged.**
  - DevTools and F12 only when `!app.isPackaged`.
  - Reload and devtools keys are blocked when packaged; zoom keys are always blocked.
  - `WEDTMD_DEBUG=1` loads `?debug=1`, unpackaged only.
- **D16 The desktop smoke attaches over CDP** (`--remote-debugging-port`). Playwright `_electron.launch` needs `--inspect`, which the `EnableNodeCliInspectArguments` fuse turns off.
- **D17 Fuses.** RunAsNode off, EnableNodeOptionsEnvironmentVariable off, EnableNodeCliInspectArguments off, EnableEmbeddedAsarIntegrityValidation on, OnlyLoadAppFromAsar on.
  - **Fallback rule (T10 only):** if the fused exe does not boot (no `app://wedtmd/index.html` CDP target within 20 s), set EnableEmbeddedAsarIntegrityValidation **off**, keep the other four, and record this in STEAM_RELEASE.md Known limitations and in the hand-off.

**Start-up order** (top level, before `ready`):
1. Set userData: `WEDTMD_USER_DATA` if it is absolute; otherwise `join(app.getPath('appData'), USER_DIR + (app.isPackaged ? '' : '-dev'))`.
2. `app.setAppUserModelId(APP_USER_MODEL_ID)`.
3. `if (!app.requestSingleInstanceLock()) app.quit()`. On `second-instance`: restore if minimized, then focus.
4. `protocol.registerSchemesAsPrivileged([{ scheme: 'app', privileges: { standard: true, secure: true, supportFetchAPI: true, corsEnabled: true, stream: true } }])`.
5. `app.whenReady()` then:
   - `protocol.handle('app', handleAppRequest)`;
   - `session.defaultSession.setPermissionRequestHandler` and `setPermissionCheckHandler`: allow only `fullscreen` and `clipboard-sanitized-write`;
   - `Menu.setApplicationMenu(null)`;
   - `registerIpc()`;
   - `createWindow()`.
6. `window-all-closed` → `app.quit()`.
7. `process.on('uncaughtException')` → append to `logs/main.log`.

**`handleAppRequest(req)` (async):**
- Parse the URL. If the host is not `wedtmd` → 404.
- `rel = decodeURIComponent(pathname)`; on a throw → 400. `'/'` maps to `/index.html`.
- `file = path.resolve(DIST_DIR, '.' + rel)`. If `file !== DIST_DIR && !file.startsWith(DIST_DIR + path.sep)` → 403.
- `fs.promises.readFile` → 200 with headers `content-type` (from MIME), `content-security-policy` (CSP), `x-content-type-options: nosniff`, `cache-control: no-cache`.
- ENOENT → 404 (text/plain + CSP).

**`createWindow()`:**
- `state = readWindowState()`. The file is `userData/window.json` with schema `{ width ≥ 960, height ≥ 540, x?, y?, maximized: bool, fullscreen: bool }`.
  - Invalid or missing → defaults, with fullscreen = `process.env.SteamDeck === '1'`.
  - Drop x/y when `screen.getDisplayMatching(bounds).workArea` overlaps the window by less than 50 %.
- `new BrowserWindow({ ...bounds, minWidth 960, minHeight 540, backgroundColor BG, show: false, title TITLE, icon: __dirname/icon.png, fullscreen: state.fullscreen, webPreferences: { preload: __dirname/preload.cjs, contextIsolation: true, sandbox: true, nodeIntegration: false, devTools: !app.isPackaged, autoplayPolicy: 'no-user-gesture-required', spellcheck: false } })`.
- `ready-to-show` → maximize if `state.maximized`, then `show()`.
- `loadURL(START_URL + (!app.isPackaged && process.env.WEDTMD_DEBUG === '1' ? '?debug=1' : ''))`.

**`writeAtomic(key, text)`:**
1. `mkdirSync(saves, { recursive: true })`.
2. `openSync(<f>.tmp, 'w')` → `writeSync` → `fsyncSync` → `closeSync`.
3. If `<f>` exists → `copyFileSync(<f>, <f>.bak)`.
4. `renameSync(<f>.tmp, <f>)`. On EPERM/EBUSY, retry up to 5× with a 40 ms synchronous sleep (`Atomics.wait`). After that, `writeFileSync(<f>)` directly and log the fallback.

### C3 Host storage: `src/persistence/hostStorage.ts` (pure) + `src/data/storage.ts`

```ts
// src/data/storage.ts
export const HOST_STORAGE = { debounceMs: 500 } as const;
export const STORAGE_TEXT = { memoryTitle: 'SAVES DISABLED',
  memoryBody: 'Storage is blocked here: progress will not be kept. Export it from SYSTEM › DATA.' } as const;

// src/persistence/hostStorage.ts
export interface TimeoutPort { setTimeout(fn: () => void, ms: number): unknown; clearTimeout(handle: unknown): void }
export interface HostStorage extends KeyValueStorage { flush(): boolean; pendingCount(): number }
export function createHostStorage(bridge: HostStorageBridge, opts?: { debounceMs?: number; timers?: TimeoutPort }): HostStorage;
export type StorageKind = 'host' | 'local' | 'memory';
export interface PickedStorage { storage: KeyValueStorage; kind: StorageKind; imported: readonly string[]; flush(): boolean }
export const IMPORT_KEYS: readonly string[] /* = [SAVE_KEY, SAVE_BACKUP_KEY, SAVE_PREIMPORT_KEY] from data/balance */;
export function pickStorage(o: { host: WedtmdHost | null; legacy: () => KeyValueStorage; timers?: TimeoutPort; debounceMs?: number }): PickedStorage;
```

**`createHostStorage` behaviour:**
- The cache is seeded from `bridge.loadAll()`; non-string values are dropped. If `loadAll` throws, `createHostStorage` throws.
- `getItem` reads the cache.
- `setItem` / `removeItem` update the cache and set `pending[key] = value | null`. If no timer is running, they start one timer of `debounceMs`. **Later writes do not restart it.**
- When the timer fires, each pending entry is sent with `bridge.set` or `bridge.remove`. Entries whose call throws stay pending.
- `flush()`:
  - clears the timer;
  - with nothing pending → returns `true` without calling the bridge;
  - otherwise calls `bridge.flush(Object.fromEntries(pending))`; `true` clears pending; `false` or a throw keeps pending and returns `false`.
- Nothing except the constructor ever throws.

**`pickStorage` behaviour:**
- With a host: try `createHostStorage(host.storage)`.
  - If `getItem(SAVE_KEY) === null`, read `legacy()`. When the legacy storage is not a `MemoryStorage`, copy every IMPORT_KEY that has a value, record it in `imported`, and `flush()` once.
  - Return kind `'host'`.
  - If creating the host storage throws, fall back to the no-host branch.
- No host: `s = legacy()`; kind is `'memory'` when `s instanceof MemoryStorage`, else `'local'`; `flush` returns `true`.
